Aprendendo a Criar Páginas Web Acessíveis

Publicado por Dev • 25 de Agosto de 2026

Adicionar imagens aos seus artigos melhora muito a experiência visual do leitor. Contudo, a acessibilidade é fundamental: o uso do atributo alt garante que leitores de tela interpretem o contexto da imagem para pessoas com deficiência visual.

Além disso, o ajuste correto via CSS impede que a imagem fique desproporcional ou atrapalhe a leitura do texto.
